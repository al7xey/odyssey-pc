# ODYSSEY PC — 3D Builder

Готовый проект сайта мастерской: React 19, TypeScript, Vite 8, Tailwind CSS 4, Three.js и небольшой Node.js API. Никаких CDN: шрифты, логотипы, текстуры и 3D-геометрия доступны локально.

## Быстрый запуск

Нужен Node.js 22.12+ (или 24 LTS). Из папки проекта:

```powershell
npm ci
npm run dev
```

Откройте http://localhost:8443. Команда запускает Vite и API на 8787; Vite проксирует `/api`. Для остановки нажмите Ctrl+C. Не запускайте одновременно dev и production на одном порту.

## Production

```powershell
npm ci
npm test
npm run build
npm start
```

`npm start` обслуживает собранный сайт и API на http://localhost:8443. Каталоги `dist`, `dist-server` и `data/quotes` размещаются рядом. Для переноса достаточно этих каталогов и Node.js: сервер использует только стандартную библиотеку. Исходники и npm нужны для повторной сборки.

За HTTPS reverse proxy задайте серверные переменные окружения:

```powershell
$env:HOST = "0.0.0.0"
$env:PORT = "8443"
$env:QUOTES_DIR = "D:\OdysseyData\quotes"
npm start
```

Proxy должен сохранять исходный `Host`; запросы формы проверяются по Origin. Создайте постоянный том для заявок и резервную копию. JSON-файлы содержат контакты: каталог не должен находиться в `dist` или быть доступен по HTTP. Ограничения: 32 КБ запроса, 10 заявок в минуту на IP, 15 секунд ожидания клиента; сервер повторно считает стоимость и проверяет совместимость. При использовании reverse proxy настройте ограничение частоты также на нём. Сервер не доверяет `X-Forwarded-For`.

Для внешней CRM задайте `VITE_QUOTE_ENDPOINT` перед сборкой. Контракт: POST JSON с `selection`, `customer: {name, contact, message}` и `consent: true`; ответ 201 `{ "id": "..." }`. Для чисто статического размещения задайте `VITE_QUOTE_ENDPOINT=none`: форма будет скачивать запрос в файл. `npm run preview` предназначен для просмотра фронтенда на 4173; API при этом нужно запустить отдельно. Для полноценной проверки production используйте `npm start`.

## Возможности

- 8 категорий комплектующих, поиск, сортировка и спецификация.
- Корпусы по конструкции: стекло спереди и сбоку, mesh-фасад, сплошной фасад, открытый стенд.
- 3D: дорожки PCB, чипы, конденсаторы, радиаторы, крепления, RGB-память, вращающиеся вентиляторы, трубки СВО, GPU и кабели.
- Наведение выделяет компонент; клик открывает его категорию. Поворот, масштаб, три камеры, режим разборки, снимок PNG и полный экран.
- Graphite / Arctic, цвет и яркость RGB, скорость анимации, стекло и качество рендера.
- Проверка сокета, длины GPU, размеров радиатора, теплового лимита охлаждения и запаса питания. При смене CPU автоматически подбирается плата; остальные конфликты исправляются кнопкой.
- Пресеты ARES / ODYSSEY / TITAN, автосохранение, JSON-экспорт и ссылка на сборку.
- Реальная запись заявки на сервер с номером; никакой имитации отправки. Заявки доступны владельцу сервера в `data/quotes`, уведомления и CRM не подключены.
- Мобильный интерфейс, управление клавиатурой, native dialog, reduced motion и fallback при отсутствии WebGL.

## Архитектура

```text
src/app/                 — граница ошибок приложения
src/entities/catalog.ts  — типы, каталог, цены, совместимость, валидация
src/features/build/      — состояние, восстановление и автосохранение
src/widgets/scene/       — React-обёртка и отдельный Three.js-движок
src/widgets/             — панель компонентов, диалоги, секции сайта
src/shared/              — иконки, миниатюры, скачивание
src/App.tsx              — композиция сайта
server/                  — Node HTTP API и production static server
scripts/                 — совместный запуск dev и API
tests/                   — проверка каталога, автоподбора и HTTP API
public/brand/            — оригинальные SVG пользователя
```

React не перерисовывает сцену каждый кадр. Движок загружается отдельно, статическая геометрия объединяется по материалу, повторяющиеся детали используют instancing. Тени кэшируются и пересчитываются при разборке. DPR ограничен (1 / 1.5 / 2); невидимая сцена и скрытая вкладка приостанавливаются, GPU-ресурсы освобождаются при размонтировании. Состояние валидируется после восстановления из браузера и ссылки.

## Проверки и настройка

```powershell
npm run typecheck
npm test
npm run build
npm run format
```

Цены каталога предварительные, не подключены к складу. Модели процедурные, а не точные CAD-модели конкретных производителей. Оценки мощности и совместимости покрывают правила встроенного каталога; окончательная проверка сборки остаётся за инженером. Перед публичным запуском замените каталог на свои товары и цены и настройте обработку заявок, условия обслуживания и юридические тексты мастерской.

Экспортированная JSON-спецификация содержит IDs и все позиции, включая сборку 8 900 ₽. Ссылка восстанавливает конфигурацию и базовую внешность; вращение и разборка всегда начинаются выключенными.
